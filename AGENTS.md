# Agent guidance: London Local News

Read [OCN video improvement system](docs/ocn-video-improvement-plan.md) before planning work on video quality, multimodal review, corrective editing, or the editorial GUI.

- This is an **implementation proposal**, not a claim that these features exist.
- Inspect the current V9 pipeline and existing GitHub issues before modifying anything.
- Preserve factual source attribution, labels for illustrative AI footage and human editorial approval.
- Prefer reuse, selective regeneration, structured correction plans and batched review.
- Make changes on a feature branch with tests and a pull request. Do not merge or publish without approval.
